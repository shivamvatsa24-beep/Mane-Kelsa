## Mane Kelsa is basically an android application where daily wage workers can get the opportunity to get the daily job.


Firebase realtime database has been used for user registration and login whereas firebase cloud storage is being user for storing profile images of the user etc !

## Major Updates (2024-2025)
### 1. GenAI Voice Assistant
Integrated **Google Gemini Pro** to enable a hands-free profile editing experience. Users can now speak their name, profession, and city in **Kannada or English**, and the AI will automatically parse and fill the registration form.

### 2. Intelligent Availability & Location
The "I am available today" toggle has been rebuilt for reliability:
- Prevents data sync loops between the UI and Firebase.
- Automatically captures and updates the worker's location when going online.
- Unified data keys (`is_available`) across all database nodes for consistent worker discovery.

### 3. Transparent Feedback System
- **Public Reviews**: Recruiters can now read all historical comments left by others for any worker.
- **Direct Rating**: Added a "Rate & Review" option directly on the worker profile to encourage community feedback.

## AIM of the MANE KELSA PROJECT

The aim of this project is to develop Android based application where a low level worker
can get a work and a normal person can get skilled worker, to get his work done. The
platform should benefit society by improving communication between low level worker
and normal person and able to provide a proper structure for giving and taking work at
lower level.
## The scope of this project Mane Kelsa includes:
- Mane Kelsa provides the opportunity of job to the daily wage workers on
   day to day basis.
- Provides impartial platform for giving and taking work at lower level.
- Supported by well-designed database and Android based design.
- A friendly User Interface is provided to facilitate different user services
